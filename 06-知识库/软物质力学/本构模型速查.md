# 不可压超弹性本构模型速查表

> 单轴拉伸情形。设 λ = λ₁ 为主拉伸，不可压 ⇒ λ₂ = λ₃ = λ^(−1/2)。
> 记号：Ī₁ = λ² + 2/λ，Ī₂ = 2λ + λ⁻²；P 为名义（工程）应力，与 Cauchy 应力关系 σ₁₁ = λP。

## 总表

| 模型 | 应变能 ψ | 单轴名义应力 P(λ) | 参数 |
|---|---|---|---|
| neo-Hookean | C₁₀(Ī₁−3) | 2C₁₀(λ−λ⁻²) | 1 个 |
| Mooney–Rivlin | C₁₀(Ī₁−3)+C₀₁(Ī₂−3) | 2(λ−λ⁻²)(C₁₀+C₀₁/λ) | 2 个 |
| Yeoh | C₁₀(Ī₁−3)+C₂₀(Ī₁−3)²+C₃₀(Ī₁−3)³ | 2(λ−λ⁻²)[C₁₀+2C₂₀(Ī₁−3)+3C₃₀(Ī₁−3)²] | 3 个 |
| Gent | −(μJₘ/2)·ln[1−(Ī₁−3)/Jₘ] | μJₘ(λ−λ⁻²)/[Jₘ−(Ī₁−3)] | 2 个 |
| Ogden (N 项) | Σᵢ (μᵢ/αᵢ)(λ^αᵢ + 2λ^(−αᵢ/2) − 3) | Σᵢ μᵢ(λ^(αᵢ−1) − λ^(−αᵢ/2−1)) | 2N 个 |
| Arruda–Boyce | μ Σᵢ₌₁⁵ cᵢ λ_L^(2−2i) (Ī₁ⁱ − 3ⁱ) | 2(λ−λ⁻²)·μ Σᵢ cᵢ·i·λ_L^(2−2i)·Ī₁^(i−1) | 2 个 |

**通用公式**：对 ψ(Ī₁, Ī₂)，不可压单轴下

> P = 2(λ − λ⁻²)·(∂ψ/∂Ī₁ + (1/λ)·∂ψ/∂Ī₂)

neo-Hookean / Yeoh / Gent / Arruda–Boyce 都是 ψ 只依赖 Ī₁ 的特例，代进去即得上表。

## 模型选择经验

| 场景 | 推荐 |
|---|---|
| 小–中应变（λ < 1.5），快速估算 | neo-Hookean |
| 硫化橡胶拉伸为主、数据有限 | Mooney–Rivlin（注意：双轴/剪切下可能不稳） |
| 填充橡胶大应变 S 形曲线（贴 0 → 上翘） | Yeoh |
| 需要物理意义的应变硬化极限（链伸直） | Gent（Jₘ）或 Arruda–Boyce（λ_L） |
| 高精度拟合、宽应变范围 | Ogden（3 项常用；警惕过拟合与参数不唯一） |

## 重要提醒

1. **拟合数据不能只给单轴**：单轴+等双轴+剪切联合拟合，参数才有预测力（Ogden 原文思想）。
2. **Drucker 稳定性**：检查 dP/dλ > 0；Yeoh 剪切模量在大 Ī₁ 时可能变负。
3. **初始模量**：小应变下 E ≈ 3μ（不可压，ν=0.5）；对 neo-Hookean，μ = 2C₁₀。
4. **凝胶要加混合自由能**：Flory–Huggins 项 + 网络弹性项，见 Hong–Zhao–Suo (2008) JMPS 56:1779。
5. 可压缩推广：把 ψ 拆成体积部分 U(J) + 偏部分，常见 U = (K/2)(J−1)²。
