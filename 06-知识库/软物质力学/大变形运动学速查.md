# 大变形（有限应变）运动学与应力速查

## 运动学

| 量 | 定义 | 备注 |
|---|---|---|
| 变形梯度 | F = ∂x/∂X | 唯一携带全部变形信息；det F = J > 0 |
| 体积比 | J = det F | 不可压：J = 1 |
| 右 Cauchy–Green | C = FᵀF | 应变的"平方"，拉格朗日描述常用 |
| 左 Cauchy–Green | B = FFᵀ | 各向同性材料本构用 B（欧拉描述） |
| 主拉伸 | λᵢ (i=1,2,3) | B (或 C) 的特征值的平方根 |
| 不变量 | Ī₁ = tr B；Ī₂ = ½[(trB)² − tr(B²)]；Ī₃ = J² | 各向同性 ψ = ψ(Ī₁, Ī₂, Ī₃) |
| 面积/线拉伸 | 单轴不可压：λ₁ = λ，λ₂ = λ₃ = λ^(−1/2) | 最常用特例 |

**不可压单轴常用结果**：Ī₁ = λ² + 2λ⁻¹，Ī₂ = 2λ + λ⁻²。

## 应力度量

| 应力 | 记号 | 定义 | 物理意义 |
|---|---|---|---|
| Cauchy（真应力） | σ | 单位**当前**面积上的力 | 真实感受的应力 |
| 第一 Piola–Kirchhoff（名义） | P | 单位**参考**面积上的力（当前方向） | 与试验机输出的"工程应力"直接对应；不对称 |
| 第二 Piola–Kirchhoff | S | 参考构型、参考方向 | 能量共轭于 Green 应变，对称 |

**换算关系**：P = J σ F⁻ᵀ，S = F⁻¹ P = J F⁻¹ σ F⁻ᵀ。

单轴不可压：σ₁₁ = λ P（拉伸比换算，别弄反：P = σ/λ）。

## 超弹性本构（不可压）

ψ = ψ(Ī₁, Ī₂) 时：

> σ = −p I + 2 ψ₁ B − 2 ψ₂ B⁻¹ （ψ₁ = ∂ψ/∂Ī₁，ψ₂ = ∂ψ/∂Ī₂，p 为待定乘子）

P = ∂W/∂F − p F⁻ᵀ（W 对 F 求导时把 p 放在不可压约束之后处理）。

能量共轭对（常用）：
- (P, F)、(S, E_Green = ½(C−I))、(σ, d，变形率)

## 小应变极限检验（自检习惯）

任何新本构，令 λ → 1+ε，应退化为线性弹性：
- σ = E ε（1D）；E = 3μ（不可压，ν = 0.5）；neo-Hookean 给 μ = 2C₁₀。
- 检查不过关 = 公式抄错了，先查这一步。
