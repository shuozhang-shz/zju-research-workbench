# 🔬 软物质力学科研工作台

为「固体力学（软物质方向）× 机器学习」研究生量身打造的本地工作台：
**一个网页仪表盘 + 一套科研流程模板 + 三件可运行的 Python 工具 + 一座知识库 + 浙大校园数据接入**。
全部离线可用，无需安装任何软件（网页部分），数据完全掌握在自己手里。

## 🚀 快速开始

1. **双击桌面「浙大科研工作台」快捷方式**（或本目录的 `浙大科研工作台.exe`）→ 应用窗口直接打开。
   它内含桥接服务，无需再启动其他东西；**关闭窗口即完全退出**。
2. 第一次使用：在「学在浙大」页登录浙大账号（建议勾选"记住密码"，之后打开即自动登录）。
3. 从「今日」页开始：设今日焦点 → 加任务 → 番茄钟开跑。
4. 也可以用 `启动工作台.bat`（自动优先启动软件）或直接双击 `index.html`（浏览器模式，功能相同，校园数据需另行运行 `启动浙大桥.bat`）。

> 建议把本文件夹固定到资源管理器快速访问，浏览器里可按 `Ctrl+D` 收藏。

## 🏫 校园数据接入（学在浙大 / 校历 / 学院通知）

「学在浙大」「校园」两个页面依赖**浙大桥接服务**（`04-代码与数据\zju-bridge\zju_bridge.py`，纯 Python 标准库，无需 pip）：

| 功能 | 数据来源 | 说明 |
|---|---|---|
| 学在浙大登录 | zjuam 统一身份认证（CAS） | 密码经 RSA 加密传输；勾选"记住密码"后用 Windows DPAPI 加密存本机 |
| 本学期课程 / 作业 | courses.zju.edu.cn | 作业按**截止时间排序**，逾期红、48小时内橙，支持筛选与本地标记 |
| 我的课表 | yjsy.zju.edu.cn（研究生教育管理信息系统） | 周次×节次网格，按教学周淡化非本周课程 |
| 考试安排 | yjsy.zju.edu.cn | 日期/时间/地点/座位号，两周内自动标红 |
| 学院通知 | saa.zju.edu.cn + saa.office.zju.edu.cn | 自动抓取并去重，新通知带 **NEW** 标记 + 侧边栏红点，可开浏览器通知；**内网通知需校园网/VPN** |
| 校历 | calendar.celechron.top（社区同步官方校历）+ 内置数据 | 时间轴、月历（假期/调课/教学周标注）、**今日日程**（今天的课+今日任务+校历事件） |
| 校车班次 | life.zju.edu.cn 后勤公开接口（班次+经停站） | **独立「🚌 班车」页**：选上车/下车校区后，不仅列直达班次，**途经上车的班次也列出并标"中途上车"**；站点链可视化（绿=上车、蓝=下车）、下一班倒计时、按星期筛选 |
| 作业提交跳转 | courses.zju.edu.cn | 每条作业带「✍️ 去提交」按钮，点击直达学在浙大该作业页面（浏览器首次需登录一次） |

**桥接常用命令**（在 `04-代码与数据\zju-bridge\` 下）：

```bash
python zju_bridge.py             # 正常启动（自动打开工作台）
python zju_bridge.py --mock      # 演示模式：假数据预览界面，不需要登录
python zju_bridge.py --check     # 网络自检：逐个检查浙大各站点可达性
```

**安全与边界**：桥接只监听 127.0.0.1；实现参考开源项目
[Celechron](https://github.com/Celechron/Celechron)、
[zju-learning-assistant](https://github.com/PeiPei233/zju-learning-assistant)、
[fiz](https://github.com/CrazySpottedDove/fiz) 的公开接口，仅访问你本人账号有权访问的数据；
请遵守学校规定，勿高频刷新。若学校改版导致接口变化，桥接会显示具体错误而不是静默失败。

## 🖥 仪表盘功能一览

| 页面 | 功能 |
|---|---|
| 🏠 今日 | 时钟/日期/周数、今日焦点、番茄钟（可配时长、计次）、今日待办快速添加、灵感闪现、自动保存草稿、数据速览、每日一句 |
| ✅ 任务 | 项目/优先级/截止日期/标签、逾期-今日-未来分组、本周战斗力进度条、搜索、编辑详情 |
| 📚 文献 | 待读→在读→已读→精读状态流、评分、标签、一句话收获、详细笔记、**一键 BibTeX 导出**（单条复制 / 全部导出 .bib） |
| 📝 笔记 | 六类笔记（科研日志/组会/实验/学习/想法/其他）、置顶、搜索、简易 Markdown 与预览 |
| 💡 灵感墙 | 随手记 idea、标记"已孵化"、🎲 随机抽签回顾 |
| 🧰 资源 | 工作台目录直达、**不可压超弹性本构速查表**、大变形运动学速查、常用软件与网站 |
| ⚙️ 设置 | 称呼/主题/番茄时长、**导出/导入 JSON 备份**、导出文献 BibTeX、清空数据 |

**数据存哪里？** 全部在浏览器 localStorage（键 `softmech_workbench_v1`），不联网、不上传。
⚠️ 三个注意：换浏览器/换电脑/清缓存数据会丢 → **每周导出一次备份**；同一台电脑上 Edge 和 Chrome 的数据互不相通；深度笔记写进 md 文件（那才是毕业要带的资产），仪表盘管动态。

## 🐍 Python 工具

```bash
cd 04-代码与数据/python
pip install -r requirements.txt        # 首次使用；PyTorch 可按官网指引装 CPU 版

python constitutive_fitting.py --demo              # 本构拟合演示（自动生成合成数据）
python constitutive_fitting.py --data 你的数据.csv  # 拟合真实单轴拉伸数据
python pinn_1d_bar.py                              # PINN 解 1D 弹性杆
python pinn_1d_bar.py --inverse                    # 反问题：从位移辨识弹性模量 E
python neural_constitutive.py                      # 神经本构：看看外推如何翻车
```

三个脚本都自带详尽中文注释和研究扩展提示，是模板不是黑盒。

## ✍️ 与 ZCode 配合的用法建议

- 读文献：把 PDF 扔给 ZCode → 总结/翻译/提取公式，产出初稿再自己核对（勿直接照搬）。
- 写论文：润色英文、检查语法、调整逻辑（内置学术写作技能）；做组会 PPT（pptx 技能）。
- 处理数据：批量整理表格（xlsx 技能）、合并/拆分 PDF（pdf 技能）。
- 写代码：让 ZCode 解释报错、重构脚本、把 1D PINN 扩展到你的课题。

## 💾 安装（Windows）

到 [Releases](../../releases) 下载 `科研工作台-Setup-1.0.0.exe`，双击安装（用户目录，无需管理员），桌面快捷方式一键启动。

不想安装？也可以直接 `git clone` 本仓库后：

- 双击 `启动工作台.bat`（浏览器模式），或
- `python workbench_app.py`（桌面应用模式，需 `pip install pywebview`）

校园数据功能在「学在浙大」「校园」页登录统一身份认证即可；校外抓内网通知需在 设置 → 账号管理 登录 WebVPN。

- 你的账号密码只保存在你自己的电脑上（勾选"记住密码"时用 Windows DPAPI 加密），不上传任何服务器
