📐 大变形运动学速查
变形梯度F = ∂x/∂X，J = det F（不可压 J = 1）
右/左 Cauchy–GreenC = FᵀF，B = FFᵀ
不变量Ī₁ = tr B，Ī₂ = ½[(trB)² − tr(B²)]，Ī₃ = J²
主拉伸（单轴不可压）λ₁ = λ，λ₂ = λ₃ = λ^(−1/2)
应力度量σ（Cauchy）；P = JσF⁻ᵀ（PK1）；S = F⁻¹P（PK2）
不可压超弹性本构σ = −pI + 2ψ₁B − 2ψ₂B⁻¹（ψ₁=∂ψ/∂Ī₁）
凝胶耦合场（提示）大变形 + 扩散耦合：Hong–Zhao–Suo (2008)、Chester–Anand (2010)，自由能 = 网络弹性 + Flory–Huggins 混合熵焓
