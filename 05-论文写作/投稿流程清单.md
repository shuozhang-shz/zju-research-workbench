# 投稿流程清单

> 从"论文写完"到"投出去"的完整 checklist。逐项打勾，避免低级失误。

## 一、投稿前定稿检查

- [ ] 图：分辨率（≥300 dpi）、配色可辨（色盲友好）、字号在缩放后可读、每个图注自含
- [ ] 公式编号、图表交叉引用全部正确（编译三遍确认）
- [ ] 参考文献格式统一（DOI 齐全，arXiv 条目格式正确）
- [ ] 全文缩写统一（PINN、FEA、PDMS……首次出现给全称）
- [ ] 数据可获取性声明（Data availability）、利益冲突声明（按刊物要求）
- [ ] 作者、单位、基金号（NSFC 格式）核对无误
- [ ] 查重（自检：句子级别的自我重复、方法描述与已发表论文雷同）
- [ ] 英文润色完成（ZCode 学术写作技能 / 导师 / 师兄过一遍）

## 二、期刊选择（讨论顺序：导师 → 组会）

- [ ] 候选 3 刊：冲刺 / 稳妥 / 保底
- [ ] 核对：期刊收稿范围（Aims & Scope）、近期是否发过同类工作、审稿周期（ lett. 类快，长文慢）
- [ ] 模板/格式要求（多数力学期刊对初稿格式宽容，但图和参考文献要先符合）

## 三、投稿材料

- [ ] Cover letter（3 段：干什么+为什么重要；与期刊范围的关系；原创性声明）
- [ ] 建议审稿人 3–5 位（不要有合作关系/同单位；给邮箱）
- [ ] 反对审稿人（有竞争关系的可列出，说明理由）
- [ ] Highlights / Graphical abstract（部分期刊要求）
- [ ] 补充材料（SM）单独成文件、正文正确引用 "see Supplementary Material"

## 四、投稿后

- [ ] 记录投稿日期与稿件号（记入项目档案）
- [ ] 预印本：投稿后可挂 arXiv（先确认期刊政策，力学类基本都允许）
- [ ] 审稿一般 1–3 个月，超过 4 个月礼貌催稿

## 五、返修（major/minor revision = 好消息）

- [ ] 逐条回复：先复述意见 → 回答 → 标注修改位置（页/行）
- [ ] 语气：感谢+专业，不卑不亢；不同意的意见要有理有据地解释
- [ ] Response letter 里引用修改稿原文，方便审稿人核对
- [ ] deadline 前提交（通常 30–60 天，来不及可申请延期）

## 六、录用后

- [ ] 校样（proof）核对：只改错别字和排版问题，大改需联系编辑
- [ ] 版权协议 / OA 费用确认
- [ ] 组内归档：终稿 + 补充材料 + 代码数据存入 04-代码与数据/
