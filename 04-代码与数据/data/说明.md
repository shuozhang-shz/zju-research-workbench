# 数据管理规范（数据/ 文件夹）

> 数据是科研的生命线。毕业答辩、论文返修、组会汇报时，"数据在哪、哪版是对的" 比什么都重要。

## 目录约定

```
data/
├── raw/          # 原始数据：只进不改！试验机导出、相机原片、仿真原始输出
├── processed/    # 处理后的数据：清洗、对齐、单位换算之后
├── figures-src/  # 作图用的最终数据集（论文图可复现）
└── archive/      # 已结题/弃用的数据
```

## 命名规范

- 格式：`日期_项目_内容_版本`，例如 `20261015_gel swell_uniaxial_v01.csv`
- 日期用 `YYYYMMDD`（保证按名排序即按时间排序）
- 禁止用 `最终版 / new / 111` 这类词；改了就升版本号 `v02、v03`
- 原始文件**永不覆盖**，处理脚本生成新文件

## 三条铁律

1. **原始数据只读**：处理链路中任何一步都不允许修改 raw/ 里的文件。
2. **处理要可复现**：尽量用脚本（Python/MATLAB）处理而非手工 Excel；脚本与数据放一起。
3. **定期备份**：至少两处（本地 + 移动硬盘/网盘），重要节点（投稿前）额外快照。

## 单位约定（全组统一，避免血泪教训）

| 量 | 单位 |
|---|---|
| 应力 / 模量 | kPa 或 MPa（写明！） |
| 长度 | mm |
| 时间 | s |
| 力 | N |

## 配套工具

- `python/constitutive_fitting.py` 可直接读取本目录下的单轴拉伸 CSV（两列：stretch, stress）。
- 表格类数据需要批量整理时，可以让 ZCode 用 xlsx 技能帮你处理。
